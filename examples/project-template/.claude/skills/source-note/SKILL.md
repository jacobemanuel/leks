# Source note

## Steps

1. `search` for the source's title and authors. When a note on it exists, update that note and write no second one.
2. Record the full reference and a stable link, such as a DOI or the official URL. Read the source itself, not a summary of it.
3. Write its main claim in your own words, and the method and evidence behind it, with page or section numbers. Quote at most one short sentence.
4. Write its limits: the setting and the sample, and what it did not test.
5. Write what it means for this project: the decision or open question it bears on, with a link to that note.
6. Save the note under `sources/`, and link it from the reading list or from the note it informs. Fix what the notes check lists when the turn ends (see AGENTS.md).

## Done when

- The note has the full reference, the claim with a page or section, the limits, and links to and from the project note it informs.
