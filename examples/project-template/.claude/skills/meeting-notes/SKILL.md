# Meeting notes

## Steps

1. Write the date and topic, and who attended (roles are enough).
2. `search` for the topics discussed and link the current decisions and state notes they touched.
3. Write each decision made, with its owner, and record it with the leks-decide skill, or with supersede-decision when it replaces one.
4. Write the action items, each with an owner, a due date, its done criteria and where the result goes.
5. Write the open questions and who answers each one.
6. Save the note as `meetings/YYYY-MM-DD-topic.md`, and link it from the state note or a meeting index. Fix what the notes check lists when the turn ends (see AGENTS.md).

## Done when

- Every decision has its own note in the log and an owner.
- Every action item has an owner and a date, and the meeting note is linked.
