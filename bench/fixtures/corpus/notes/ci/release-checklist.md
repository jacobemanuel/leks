# Release checklist

1. Tag the commit.
2. Build the bundles from the tag.
3. Run the smoke test on each device class.
4. Compare bundle hashes with the nightly build.
5. Publish the docs for the new version.
6. Archive the previous minor version of the docs.
7. Announce the release in the team channel.
